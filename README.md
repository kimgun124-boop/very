# 밸류체인 신고가 보드

우성님 자료와 리포트, 엣지방 종목 총정리(9/22~24)에 나온 상장사 약 600개를 한 화면에서 봅니다.

- 현재가·등락률 (네이버 금융, 장중 수 초 지연)
- 52주 최고가, 괴리율, 신고가까지 필요한 상승률, 52주 안에서의 위치
- 신고가를 찍은 뒤 지난 거래일 수, 정배열(현재가 > 20일선 > 60일선 > 120일선) 여부
- 신고가 돌파 유지: 52주 신고가를 처음 쓴 날부터 종가가 기준가(돌파선 또는 첫날 종가) 위에 머문 거래일 수, 한 번이라도 아래면 '이탈'
- 종합 RS(오닐 방식 가중 수익률 백분위)·단기 RS(1M)·RS(3M·6M), 2주(10거래일) ATR%
- 영업이익·EPS 정배열 필터: 최근 실적 2~3년 + 컨센서스(E)까지 해마다 증가한 국내 종목만
- 주도섹터 레이더: 최근 N거래일 안에 신고가를 쓴 종목이 2개 이상인 분류
- 종목별 한 줄 설명과 1년 차트, 자료 원문 메모
- 맨 위 시장 요약: 코스피·코스닥 지수와 전일대비, 상승·보합·하락 종목 수, 외국인·기관·개인 순매수, 오늘의 시장 분위기
- 투자자별 순매수: 시장 전체는 기관 세부(금융투자·보험·투신·은행·기타금융·연기금·기타법인)까지,
  종목별은 개인·외국인·기관 순매수(표의 수급 열, 종목 자세히 보기의 수급 탭)

## 처음 한 번만: 설치 (윈도우)

1. **파이썬 설치**
   https://www.python.org/downloads/ 에서 내려받아 설치해요.
   첫 화면 아래의 **"Add python.exe to PATH"** 체크박스를 꼭 켜고 설치하세요.
2. 받은 zip 파일의 압축을 풀어요. 바탕화면 같은 곳에 두면 편해요.
3. 폴더 안의 **setup.bat** 을 더블클릭해요. 1~3분 정도 설치가 진행돼요.

## 매번: 실행

- **run.bat** 을 더블클릭하면 브라우저에 보드가 열려요. 주소는 http://localhost:8501
- 끌 때는 까만 창을 닫으면 돼요.
- 같은 와이파이의 휴대폰에서도 볼 수 있어요. 까만 창에 나오는 `Network URL` 주소를 휴대폰 브라우저에 입력하세요.

## 종목 추가·수정

`stocks.py` 를 메모장으로 열고 아래 형식으로 한 줄을 넣어요.

```
("반도체", "후공정 테스트 장비", "종목명", "123456", "한 줄 설명"),
```

코드를 모르면 `""` 로 비워 둬도 돼요. 앱이 네이버 검색으로 이름이 똑같은 종목을 찾아 코드를 붙여요.
못 찾으면 "데이터 점검 필요"에 후보가 나와요.

코드를 넣은 뒤 **verify.bat** 을 실행하면 코드와 네이버 종목명이 맞는지 점검하고,
틀린 경우 후보 코드를 찾아줘요. 처음 받았을 때도 한 번 돌려 보는 걸 권해요.

## 문제가 생기면

- **화면에 "데이터 점검 필요"가 뜸**: 코드가 틀렸거나 사명이 바뀐 종목이에요. verify.bat 으로 확인하세요.
- **모든 종목이 조회 실패**: 인터넷 연결을 확인하세요. 네이버가 응답 형식을 바꿨다면 `data.py` 의 `parse_*` 함수를 고쳐야 해요.
- **인터넷 없이 화면만 보고 싶을 때**: demo.bat 을 실행하면 가짜 데이터로 열려요.

## 참고

- 시세는 네이버 금융 공개 페이지에서 가져와요. 개인 참고용으로만 쓰고, 매매 전에는 HTS 시세를 확인하세요.
- 52주 최고가는 장중 고가 기준이에요. 일봉은 30분마다, 시세는 선택한 주기마다 새로 받아요.
- 종목 설명은 자료 작성 시점(2023~24년) 기준 요약이라 최신 사업 현황과 다를 수 있어요.
- 종목별 수급 금액은 순매수 수량 × 그날 종가로 계산한 추정치예요. 종목별 연기금·투신 세부는 네이버가 주지 않아서
  시장 전체 기준으로만 보여줘요(한국거래소 데이터는 2025년 말부터 로그인이 필요해요).
